# Amberra — Арт-дирекшн предметной съёмки

Цель: закрыть единственный реальный luxury-гэп сайта — товарные фото на чистом
белом (`#FFF`), которые «вырезом» бьются с тёмно-янтарным фоном сайта. Референс
планки: Bvlgari, Jacob&Co, David Yurman — где предмет и фон живут в одной
световой среде, а не наклеены прямоугольником.

Проверено на проде: 94 картинки — непрозрачный webp 1400×1400 с впечённым белым.
Тёплый фон карточки не поможет (белый фото перекрывает). Правится только на
уровне изображения.

## Два пути

### Путь 1 — Interim (быстро, без съёмки): bg-removal + тёплая карточка
Снять белый фон у существующих 94 webp → прозрачный PNG, поставить тёплую
кремовую карточку (`--cream #FAF8F5`) + мягкую тень. Предмет «сядет» в палитру.
- Плюс: 1–2 дня, без фотографа, сразу поднимает ощущение.
- Минус: авто-удаление белого рискует съесть светлые части (блики янтаря,
  серебро, тонкие цепочки). НЕ гнать массово вслепую — пилот на 3–5 сложных
  (цепочка, светлый янтарь, серебро) с ручной проверкой, потом решение.
- Готов запустить пилот по команде (ImageMagick floodfill / rembg), покажу до/после.

### Путь 2 — Reshoot (правильно, планка Jacob&Co)
Пересъёмка на единой арт-дирекшн. Ниже — ТЗ.

## ТЗ на съёмку

**Фон**
- НЕ чистый белый. Тёплый градиент-подложка: кремовый→песочный
  (`#FAF8F5` → `#EDE4D3`), либо тёмная люкс-подложка в тон сайта
  (`#1c1308`→`#3a2a10`) для драматичных кадров коллекций.
- Единый фон для ВСЕХ карточек каталога (сейчас разнобой ломает сетку).

**Свет**
- Мягкий рассеянный ключ + тёплая заливка (2700–3200K) — янтарь должен светиться
  «изнутри», не бликовать плоско. Софтбокс сбоку 45°, отражатель снизу.
- Один световой рисунок на всю линейку = визуальная консистентность.

**Ракурс/кроп**
- Единый: предмет по центру, ~70% кадра, одинаковый масштаб для однотипных
  (все кольца — один размер в кадре, все серьги — один).
- Серьги — пара симметрично; кольца — 3/4 с видом на камень; подвески — фронт
  + деталь цепочки.

**Технич.**
- Квадрат 1:1, ≥2000×2000, экспорт webp q78 + прозрачный PNG-мастер.
- Тень контактная мягкая (не жёсткая), одинаковой плотности по линейке.

**Консистентность (главное)**
- Один фон, один свет, один масштаб, одна тень — по всем 94. Сейчас именно
  разнобой карточек = основной не-luxury сигнал, а не качество отдельного фото.

## Приоритет
Бестселлеры (главная, 6 шт) → топ-категории (кольца/серьги) → остальное.
Замена пофайлово (тот же slug/имя) — вёрстка и schema не трогаются.
